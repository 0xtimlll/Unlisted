# Roboto Mono

Self-hosted copy of **Roboto Mono** (variable weight 100–700, latin and latin-ext subsets), taken
from Google Fonts' own build (`fonts.gstatic.com/s/robotomono/v31/…`). Licensed under the SIL Open
Font License 1.1 — see `OFL.txt` (the upstream project: https://github.com/googlefonts/robotomono).

Served from this origin so the page loads nothing from a third-party host (`font-src 'self'`).
